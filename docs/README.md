**中文阅读顺序：** 先看项目首页了解用途，再看模型与复现说明，最后结合历史结果、研究笔记和文献索引深入阅读。历史笔记保留当时的讨论，当前运行前提和验证范围以项目首页及模型指南为准。

A new simulation can overwrite profiles and local logs. Preserve a separate run directory before following generation or launch instructions. The saved result tables are historical outputs, not results regenerated by this documentation refresh.
