## 三、源码改动一览（老师问「你改代码了吗」）

| 文件 | 改了什么 | 为什么 |
|---|---|---|
| `slurm_simulator/src/common/slurm_protocol_api.c` | 模拟器 RPC 路径设置 `restrict_uid` | 否则 Slurm 23.11 启动 fatal |
| `slurm_simulator/contribs/sim/slurmctld_controller.c` | 节点注册时让所有配置节点上线 | 否则只有 1 节点，多节点 MPI 无法调度 |
| `slurm_simulator/contribs/sim/slurmctld_agent.c` | 丢弃 PING / HEALTH_CHECK 等请求 | 否则模拟器 abort |
| `slurm_simulator/src/common/assoc_mgr.c` | 无 slurmdbd 时 assoc 刷新失败仍继续 | 否则大量 `invalid account`，调度卡死 |
| `slurm_simulator/stanage-sim/slurm.conf` | 新建 Stanage 1:1 配置 | 导师要求的集群还原 |
| `slurm_simulator/stanage-sim/sim.events.realistic` | 新建 140 作业真实负载 | 替换 placeholder |
| `slurm_simulator/workload-gen/generate_workload.py` | 新建 workload 生成器 | 可复现、可调参 |
| `slurm_simulator/workload-gen/analyze_run.py` | 新建能耗/碳排放分析 | 项目核心输出 |
| `slurm_simulator/run-stanage.sh` | 新建 Stanage 运行脚本 | 一键 demo / verify / realistic |
